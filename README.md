A one-line fortune cookie message an AI agent would crack open: a warning every working agent recognises at once — the user who says "just one more thing" has said it eleven times.

## Run it

```sh
node main.ts
```

The program prints the fortune to stdout and writes the exact same text, with no trailing newline, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
